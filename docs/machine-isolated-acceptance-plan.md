# 单台非业务机器隔离验收准备方案

当前只准备单台候选节点的隔离验收，不创建云机、不部署服务、不接正式数据库，不调用云平台或正式面板接口。真实自动创建、自动轮换、DNS 切换继续关闭；不读取、接管或改动现有 tanzhen。

本轮交付是参数表和只读预检清单，不是开测许可。参数齐备后仍须单独授权隔离环境搭建和一次性手动验收。缺项表示尚未指定或核实本次测试用途，不表示线上没有相应资源。

## 待你确定的四项参数

| 参数 | 本轮需要填写 | 当前状态和约束 |
| --- | --- | --- |
| 凭证分组 | 专用测试分组名称或 ID，并确认其中账号不与 tanzhen 或正式业务混用 | 待指定。首轮建议分组只放一个专用 Linode 测试账号，保持分组选取，不依靠多账号自动轮换。这里只需要名称或 ID，不要提供 Token。 |
| 地区和机型 | 从当前支持的区域、规格、镜像中确认一组 | 待确认。当前本地白名单为区域 `sg-sin-2` / `jp-tyo-3`，规格 `g6-standard-4`，镜像 `linode/debian12`。这些是代码允许的 ID，不是实时可售、容量或价格证明。 |
| 预算 | 实例月费报价上限 USD、本次测试费用审批上限、允许保留时长及结束后的处置意向 | 待填写。候选机数量上限拟定为 1，策略的滚动 24 小时创建尝试上限拟定为 1。任何创建或保留均未获本方案授权。 |
| 测试协议 | 首轮协议、一个专用节点及对应端口 | 待确认。建议先验 HY2；现有 worker 已有真实 HY2 回环测试，但公网验收尚未完成。TUIC、Trojan、VLESS 目前不能以配置适配器存在代替协议互通验收。 |

月费报价上限只约束当前创建前检查的实例月价，不等于测试实付封顶、账号余额监控或超支自动删除。额外带宽、附加资源和保留时间应另行核对；不从模拟测试中的价格推断真实报价。当前没有查询价格或验证账号权限。

现有策略字段中的 `monthly_limit_usd` 和 `daily_limit` 分别承担报价与创建次数校验；“本次测试费用审批上限”和“最长保留时长”是待批准的操作边界，不是已经实现的账单熔断或到点自动删机功能。

可按以下格式回复，不需要密钥、密码或用户信息：

```text
测试凭证分组名称或 ID：待填
确认不与正式业务及 tanzhen 共用账号：待确认
地区 / 机型 / 镜像：待选
实例月费报价上限 USD：待填
本次测试费用审批上限 / 最长保留时长：待填
首轮协议 / 专用端口：待选
结束后保留或申请删除：待确认
```

## 隔离资源方案

首轮拟采用 Linode。DigitalOcean / Vultr 的目录和资源管理能力不代表当前单台创建链路已经支持它们；当前 `localChecks()` 对非 Linode 创建仍会阻断。

```text
独立测试面板
  独立数据库、Redis 命名空间、队列和应用密钥
  独立 HTTPS 回调入口
       |
       | 后续另行授权的一次性创建意图
       v
1 台全新非业务候选机
  cloud-init 安装 kelinode-rs
  本次任务独有的安装 ID、发行物和 SHA256
  专用逻辑机器、专用节点组和临时测试身份
       ^
       | 真实协议 TCP / UDP
独立受控验收客户端位置
  HTTPS 验收 worker、固定回显目标、有限期 profile
```

“单台”只指候选云机，不代表验收端也运行在候选机内。验收客户端应位于候选机之外，可以使用另行授权的既有非业务环境，不要求现在增购机器。完整的旧机替换测试会同时涉及旧源机和新候选机，属于另一阶段；本轮不验证真实 DNS 切换。

当前向导要求本次独立创建任务的来源记录。已有普通机器、旧安装 ID、历史回执、同名版本或旧云资源不能充当新建成功证明。新方案不导入 tanzhen 脚本，`source_ref` 保持空。

## 需要补齐的配套资料

| 项目 | 准备内容 | 当前状态 |
| --- | --- | --- |
| 测试面板 | 独立 HTTPS origin、回调入口、管理员、数据库和 Redis 的隔离方案，不复制正式 `.env` 或应用密钥 | 待规划，未部署 |
| 逻辑机器和节点 | 拟定专用机器、节点组和至少一个测试节点；没有正式用户、旧任务、旧实例上报、旧 DNS 或云资源绑定 | 待规划，尚未分配 ID |
| 发行物 | `kelinode-rs` 发行记录 ID、`linux-x86_64` 平台、版本、可获取的安装包及二进制 SHA256；安装结果须与固定发行物一致 | 待选定，不沿用历史灰度哈希或夹具版本 |
| 国内 IPv4 探测 | 明确允许探测的目标列表、5 秒间隔和配置修订；仅在隔离面板配置 | 目标列表待确认，不读取或改写正式配置 |
| 验收客户端宿主 | 独立非业务 Linux 运行位置、Python 3.11 及以上、SHA256 固定的 sing-box、非 root 服务和资源限制 | 待确认，不安装或启用服务 |
| HTTPS 验收入口 | 固定 verifier URL、TLS 身份校验、密钥的安全存储位置，以及策略 ID 到 profile 的映射 | 待规划，不生成或发送密钥 |
| 测试身份和回显 | 专用协议身份、TLS 名称或证书指纹、固定回显地址和端口、到期与撤销责任人 | 待规划，不创建账号或开放通用代理 |
| 排障入口 | 服务商控制台可用；若后续需要 SSH，则单独核验主机公钥指纹并使用专用公钥 | 待确认，不连接机器。当前单台向导的 `authorized_keys` 为空，不能假设已自动安装 SSH 公钥 |

本阶段不需要业务 DNS 凭证或切换记录。测试面板和 verifier 的 HTTPS 地址属于通信入口准备，不能据此修改已有业务解析。

候选公开 IPv4 只能在后续获授权的创建回执和云资源身份核对后确定，现在不要求预填。先规划固定的策略到 profile 映射；以后仅把确认后的该候选 IP 加入 worker 及网络白名单，再验证转发。不能为避免等待 IP 而提前允许任意地址或整个网段。

## 只读预检清单

这里只列后续检查方式；除下表中的离线代码项外，实际环境项目均未执行。状态不能把未知写成通过，也不能为取得绿灯而放开执行闸门。

| 编号 | 检查内容 | 检查方式及通过条件 | 状态 |
| --- | --- | --- | --- |
| R01 | 创建与自动执行边界 | 本地默认 `allow_live=false`、测试机器白名单为空；故障转移 runner、replacement 关闭；原生执行硬闸仍拒绝执行 | 本地代码已核对，不代表已读取线上运行配置 |
| R02 | 验收与 DNS 边界 | 本地默认 `allow_verification=false`、`allow_dns=false`、策略白名单为空；本轮不启用自动轮换，也不运行任何队列或调度命令 | 本地代码已核对 |
| R03 | 测试环境归属 | 以后只读取隔离环境的连接目标、schema 标识、Redis 前缀和任务命名空间；与正式环境、tanzhen 完全分离 | 待隔离方案确定后核对 |
| R04 | 分组和账号 | 只查看隔离配置或已批准的脱敏清单中的分组 ID、成员、服务商、修订及身份指纹；本轮账号用途明确，非共享业务账号 | 待指定分组 |
| R05 | 账号健康与历史任务 | 使用既有缓存确认权限、冷却、创建次数和未结束意图；缓存缺失、权限未知、账号身份或分组修订变化均阻断 | 待核对，不自动触发健康刷新或新检查记录 |
| R06 | 服务商目录和费用 | 读取既有目录/报价缓存，核对区域、镜像的 cloud-init/Metadata 能力、规格及报价；目录过期、强制备份或超预算均阻断 | 实时状态未核实；后续访问服务商只读 API 也需明确授权 |
| R07 | 专用机器和节点组 | 仅在隔离环境检查机器启用、至少一个测试节点、节点组独占、没有旧来源或正式绑定，测试 slot 为空 | 待规划与核对 |
| R08 | 发行物一致性 | 读取发行清单和本地校验结果，固定发行 ID、平台和二进制 SHA256；不只比版本文字，也不把压缩包哈希当二进制哈希 | 待选择发行物 |
| R09 | 入口与证书方案 | 核对 origin、verifier 地址、TLS 信任、目标/端口白名单和回调方向；不得跳过证书校验或允许任意 URL | 待入口方案；网络连通性尚未实测 |
| R10 | IPv4 证据口径 | 读取隔离配置和既有样本：任一已配置目标可达为绿；全失败须有同来源健康基线及连续完整失败样本；过期、未知或无来源归属不判红，IPv6 不作依据 | 规则已核对；目标、实时样本待提供 |
| R11 | worker 及临时身份 | 核对程序哈希、私有文件权限、非 root 运行、进程/内存边界、profile 的精确目标 IP 和有效期，以及身份撤销方案 | 设计和样例已存在，实际宿主与边界待验收 |
| R12 | 回执和成本结案 | 明确只保留任务标识、阶段、聚合计数、回执摘要及清理状态；云资源保留、删除申请及费用核对各有责任人 | 待确定责任人与处置意向 |

“只读”不包含保存策略、刷新云清单、运行凭证健康检查、采集费用基线、生成任务或执行验收。这些动作可能写缓存、审计或任务记录；本轮均不调用。只读清单不得直接调用 `queue`、`enroll`、`verify`、取消任务、迁移、安装、重启或任何 DNS 写入。

## 未来真实验收的独立准入

以下步骤只作为后续方案，不在本轮执行。

1. 确定四项核心参数和配套资料，完成隔离边界复核。资料齐备只表示可以申请开测，不表示向导的 `creation_allowed` 应变为真。
2. 单独授权独立测试环境的搭建、只读服务商核验和有限期临时身份。只读 Token 或分组名称不能代替创建权限，生产账号的权限不因此扩大。
3. 单独授权最多一台候选机的一次性手动创建。只在隔离测试实例内批准指定机器和策略的白名单及所需单台创建/验收门槛；不修改正式配置，不开放全局自动创建、自动轮换、DNS 切换或原生自动故障转移硬闸。当前没有浏览器或环境变量开关可绕过这些限制。
4. 创建前重新取得有效预检；其回执有效期为 120 秒，并绑定管理员、策略修订、发行物和目录/凭证上下文。只沿原请求 ID 跟进，超时或结果未知只核对原意图，不自动换账号或再发创建请求。
5. 核对新安装 ID、创建标记、云资源身份、公开 IPv4、派发后的 Agent/节点上报、进程会话、二进制摘要和配置投影，再执行受控公网转发验收。安装脚本最长 600 秒，创建任务期限当前默认 1200 秒；超时不等于资源不存在。
6. 结束时先核对临时客户端、socket 和私密文件清除，再由身份所有者撤销服务端临时身份和 profile。单独记录云机及预算仍然保留的状态；任何删除、关机、预算释放或扩大测试范围都需另行授权。

独立单台验收服务与自动故障转移原生执行桥是不同入口；临时授权隔离单台测试不等于开启全局自动化。当前本地所有执行门槛保持原样，没有为这份准备方案做任何放行。

## 未来通过条件与限制

- 候选机必须来自本次独立任务，安装 ID、发行物、节点及公开 IPv4 对应一致，且没有正式业务或 tanzhen 资源混入。
- 国内 IPv4 探测按项目口径记录，不能把 ICMP 结果当成全部协议的公网转发证明；后者单独测试。
- worker 仅允许本策略、本候选公开 IPv4 和约定节点/端口；profile 有效期须在核验时至少剩余 30 秒且不超过 1 小时，续期须显式授权。
- 每个节点 TCP 和 UDP 都必须收到原始 3 个不同的 32 字节回显帧，无缺失、无重复且摘要一致；TLS 身份、签名、单次 challenge 和回执时效均通过，临时客户端清理完成。
- 这 96 字节是每传输的合成应用负载，不是完整网络计费字节，也不是吞吐峰值或 P99 指标。单台 HY2 就绪通过，不代表其他协议、多地区、自动换机或 DNS 切换已验收。
- 错误密码、错误 TLS 身份、服务端身份撤销和重放等负例，须在另行批准的公网测试用例中单独记录；不能把已有回环测试结果填作公网通过。
- worker 不会创建或撤销服务端账号；`cleanup_complete` 不能替代临时身份撤销证明。任务默认 `delete_strategy=keep`，取消、超时或客户端清理完成都不代表云资源已经删除或费用已经结清。
