# lab-failover-01：V2 与阿里云 DNS 模拟验收

2026-11-19（北京时间），基于 `984af21185a71879425a9796aadc22ef8f745d62` 的本地隔离验收通过。先在仅监听回环地址的 MySQL 5.7.44 临时库中跑 V2，再给同一服务挂载阿里云模拟记录集。所有探测、上报、云平台和 DNS 回执均为模拟数据。

## V2 故障转移

成员 A 是唯一替换目标，成员 B 作为健康对照。A 的触发阈值为连续失败 3 轮，每个场景最多一次候选创建。

| 场景 | 验收结果 |
| --- | --- |
| 任一探测目标可达 | A 保持健康，不创建候选，不切换 DNS。 |
| 无既往健康基线，连续失败 | 前 3 轮没有派发创建；达到阈值后仅派发 1 次模拟创建。候选初始化、连续上报及 IPv4 可达性检查通过后，才模拟切换和读回。 |
| 候选 IPv4 不可达 | 停止本次替换，不切换 DNS。 |
| 创建回执不明确 | 只核对原请求，无法确认则进入待核查；不重复创建，不切换 DNS。 |

四个场景均未对 B 派发任何操作。B 保持健康，成员配置和关联策略在整轮前后完全一致。

## 阿里云 DNS 记录集

模拟记录集使用保留的 `.test` 域名，TTL 为 600 秒。A、B 各有 4 条记录，即默认和电信线路各一条 `A` 与 `AAAA`。

| 场景 | A 的结果 | B 的结果 |
| --- | --- | --- |
| 正常切换 | 仅更新 4 条原记录的目标地址，每条写一次并读回验证；TTL、归属、线路及记录 ID 均不变。 | 4 条记录逐字段不变。 |
| 存在归属不符的记录 | 阻断整个切换，零写入，原记录保留。 | 4 条记录逐字段不变。 |
| 写入生效但丢失回执 | 通过读回确认已生效；4 条记录仍各写一次，没有重复写入。 | 4 条记录逐字段不变。 |

TTL 模拟先报告等待 600 秒；推进模拟时钟后，默认线路匹配，电信线路未被解析夹具观测，结果仅为 `partial_scope`。没有发起真实解析查询，也不代表真实 DNS 已传播。

## 边界与清理

临时 MySQL 已停止，测试库和运行目录已清理。外部 HTTP 请求、真实任务和队列投递均为 0。未访问或配置正式面板，未部署、未建机、未写真实 DNS，未更改生产门禁或自动开关，也未操作 Agent 或 tanzhen。

本轮证明的是本地模拟中**只替换成员 A，成员 B 不受影响**，不作为真实云机、生产接管或外部 DNS 生效的验收证明。
