# 独立工作器故障恢复与队列隔离验收

验收日期：2026-11-28（北京时间）。使用隔离 Linux、独立 MySQL/Redis 和模拟 Linode、DNS。没有连接正式数据库或队列，未启动正式工作器，未改线上封存包、#17、DNS 或自动开关。

## 失败记录与修复

- 在线上已结束的隔离空队列试启动中，R2 退出码为 1，未出现心跳。启动外壳使用了 BusyBox `timeout` 不支持的参数，PHP 还未启动。后续启动器验证保留了 90 秒硬截止和 PHP 启动前的脱敏首错；这里不把空队列心跳当作真实任务恢复证据。
- Linux 首轮发现独立 Redis 身份缺少所选凭证组的目录缓存键。只加入该组的精确缓存键，不扩大到其他凭证组或业务队列。独立工作器显式关闭共享失败任务记录，仅由专用推进器恢复原手动任务，不转投旧队列。
- SIGKILL 不会立即释放成员的 Redis 锁。早期的 165 秒观察少于成员锁最长 300 秒，不能据此判定无法恢复。随后两次复验中，合成旧回执过期、业务夹具先到运行时限，分别导致整组不完整。最终只延长夹具的有效期或运行时间，未缩短真实任务租约和成员锁。
