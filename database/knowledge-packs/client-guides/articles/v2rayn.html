v2rayN 使用教程

v2rayN 主要适合 Windows 桌面端用户。建议使用较新的正式版，旧版本可能无法识别 Hysteria2、Reality 或较新的 sing-box 配置。

准备订阅链接

请先复制用户中心的订阅链接。不要复制浏览器地址栏里的后台地址，也不要只复制 token。

你的订阅链接：{{subscribeUrl}}

导入步骤

  1. 打开 v2rayN，进入订阅分组或 Subscription group settings。
  2. 点击添加，备注填写 {{siteName}}。
  3. URL 处粘贴订阅链接，然后保存。
  4. 返回主界面，选择更新订阅，不通过代理或更新全部订阅。
  5. 节点出现后，右键选择一个节点设为活动服务器。
  6. 开启系统代理，路由模式建议选择绕过大陆或规则模式。

旧版本处理

  • 如果更新后没有节点，先升级 v2rayN 到新版。
  • 如果只显示少量节点，可能是当前版本不支持某些协议。
  • 如果系统代理无效，请以管理员身份运行或检查 Windows 代理设置。
常见问题

提示订阅失败时，先复制订阅链接到浏览器测试能否打开。如果浏览器也无法打开，请检查账号套餐状态、流量是否耗尽、订阅链接是否被重置。
