v2rayN 使用教程

本教程以 Windows 版 v2rayN 为例。建议使用较新的正式版，并同时核对出问题的协议实际使用的内核及版本。

v2rayN 应用版本不等于 Xray、sing-box 或其他内核的版本。请在 Core 类型设置、内核管理或启动日志里确认。不要把所有协议统一切成同一个内核；本站 TrustTunnel 与 ECH 的导出要求见“客户端与内核兼容说明”。

准备订阅链接

请先复制用户中心的订阅链接。不要复制浏览器地址栏里的后台地址，也不要只复制 token。

你的订阅链接：{{subscribeUrl}}

导入步骤

  1. 打开 v2rayN，进入订阅分组或 Subscription group settings。
  2. 点击添加，备注填写 {{siteName}}。
  3. URL 处粘贴订阅链接，然后保存。
  4. 返回主界面，选择更新订阅，不通过代理或更新全部订阅。
  5. 节点出现后，右键选择一个节点设为活动服务器。
  6. 开启系统代理，路由模式建议选择绕过大陆或规则模式。

旧版本处理

  • 如果更新后没有节点，先升级 v2rayN 到新版。
  • 如果只显示少量节点，可能是当前版本不支持某些协议。
  • 如果系统代理无效，先确认系统代理已开启、端口未冲突且没有其他代理软件覆盖设置；仅在需要 TUN 等权限功能时按官方说明授权。
常见问题

提示订阅失败时，先查看更新结果中的 HTTP 错误、超时或解析错误，再检查账号套餐、流量和当前订阅链接。不要把完整链接交给第三方测试网站。

同一节点在 Xray 正常、切换 sing-box 后失败时，固定网络与节点，分别记录内核版本和错误，再联系支持核对传输兼容；不能仅凭这个结果认定服务器版本太新。切换内核后先停止旧连接，再启动测试。
