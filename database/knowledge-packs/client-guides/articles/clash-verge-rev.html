Clash Verge Rev 使用教程

Clash Verge Rev 适合 Windows、macOS 和 Linux 桌面端用户。它适合需要规则分流、系统代理和桌面托盘控制的场景。

准备订阅链接

请在用户中心复制订阅链接。复制后不要修改链接中的 token。

你的订阅链接：{{subscribeUrl}}

导入步骤

  1. 打开 Clash Verge Rev，进入订阅或 Profiles 页面。
  2. 点击新建、导入或加号按钮，选择从 URL 导入。
  3. 名称填写 {{siteName}}，URL 粘贴订阅链接。
  4. 保存后点击更新，等待配置下载完成。
  5. 进入代理或 Proxies 页面，选择自动选择、故障转移或指定节点。
  6. 回到首页打开系统代理，需要全局代理时再切换为全局模式。

建议设置

  • 日常使用建议选择规则模式，国内网站会自动直连。
  • 如果浏览器仍无法访问，请确认系统代理已经开启。
  • 如果订阅下载失败，尝试关闭本机其他代理软件后重新更新订阅。
常见问题

节点可以看到但无法连接时，先切换其他节点，再检查 Clash Verge Rev 内核是否已经启动。配置更新失败通常和订阅链接复制不完整、本机网络无法访问订阅地址有关。
